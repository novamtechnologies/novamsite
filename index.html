Core Technology

Three technologies.

Each technology is co-designed with the others. The control software is tuned to this specific airframe, and the navigation system feeds the same state estimator that underpins it. Neither works at full capability without the other.

Competitive Moat

Copy one piece.
Get nothing.

The three technologies are co-designed. No single component functions at full capability without the other two. The integration is the invention.

Copy the BWB airframe

Without control software tuned to this airframe's instability, the aircraft is aerodynamically uncontrollable.

Result → unflyable

Copy the control software

Tuned to specific aerodynamic coefficients validated by OpenFOAM CFD on EVO-T's geometry. No transferability to another airframe without repeating the full design loop.

Result → non-functional

Build GPS-denied navigation

Without integration as a position measurement in the flight controller's state estimator, it remains an instrument display — not a flight control input.

Result → fragmented

Integrate all three from scratch

Requires the same iterative loop of CFD aerodynamic modelling → control design → sensor fusion → hardware-in-the-loop testing that Tokyo Dynamics has been executing since 2021. The aerodynamic model, control software and sensor fusion cannot be purchased or downloaded.
